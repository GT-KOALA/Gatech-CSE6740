RNN and LSTM: reading text, one word at a time

CSE 6740 • Actual training on the UCI SMS Spam Collection. Both networks learn word embeddings and classify messages as legitimate (ham) or spam.

1. Words → embeddings → recurrent memory → prediction

"free entry ..." → lowercase word / number / punctuation tokens
→ learned 32-dimensional embeddings
→ RNN or LSTM (48 hidden units; shared weights across time)
→ final real token's hidden state → linear layer → P(ham), P(spam)

RNN

hₜ = tanh(Wₓ eₜ + Wₕ hₜ₋₁ + b)

LSTM

iₜ, fₜ, oₜ = sigmoid(affine(eₜ, hₜ₋₁))
gₜ = tanh(affine(eₜ, hₜ₋₁))
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ gₜ
hₜ = oₜ ⊙ tanh(cₜ)

Vocabulary comes only from training messages. Unseen tokens map to <UNK>. Messages are capped at the first 64 tokens. Padding is ignored by selecting the final real token, not the final padded position.

2. Replay learning

Blue: RNN. Orange: LSTM. Solid: training spam F1; dashed: validation spam F1. This replays saved measurements, including random initialization at epoch 0.

F1 balances spam precision and recall. Validation loss selects each checkpoint; the held-out test set is evaluated after selection. Both use Adam (0.002), batch size 64, and gradient clipping (norm 1). Equal hidden width gives the LSTM more recurrent parameters.

3. Evaluate on unseen messages

One seeded run, one fixed split. These results demonstrate the models; they do not establish a universal ranking. Exact normalized duplicates are removed before splitting; near-duplicate spam templates may remain.

4. Watch the models read

Pick an unseen test message. Reveal it token by token, then compare the evolving spam probabilities. The final-trained classifiers are applied to prefixes; prefix predictions were not explicitly supervised.

5. Inspect the trained LSTM

Select one of 48 learned units; scrub the message to connect each word to the memory update. Gates are computed using the actual selected checkpoint weights and verified against PyTorch.

Orange: cell c. Blue: hidden h. Input i, forget f, output o range from 0 to 1; candidate g and hidden h range from −1 to 1. Cell state c is unbounded. One unit need not correspond to one human-readable concept.
